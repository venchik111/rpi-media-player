# Документация rpi-media-player

Минимальный образ Linux для Raspberry Pi 4 Model B. Плата поднимает свою Wi-Fi сеть и
раздаёт загруженное видео бесконечным потоком HLS, как IP-камера. Файлы заливаются по SFTP.

## Коротко

| | |
|---|---|
| Плата | Raspberry Pi 4 Model B |
| Карта памяти | от 512 МБ, образ занимает 464 МБ |
| Wi-Fi | сеть `rpi-cam`, пароль `camera1234` |
| Поток | `http://192.168.50.1:8080/stream.m3u8` |
| SFTP и SSH | `192.168.50.1`, порт 22, `media` / `media` или `root` / `player` |
| Папка с видео | `/data/media` |

Это значения по умолчанию, они меняются в [`rpi-player.conf`](configuration.md).

## Текущий статус

Образ проверяется в эмуляторе: см. [Тестирование](testing.md). Работа Wi-Fi-чипа и
аппаратного кодера на настоящей плате этими проверками не подтверждается.
