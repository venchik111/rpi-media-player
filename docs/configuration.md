# Настройка

Все настройки лежат в файле `rpi-player.conf` на разделе `BOOT` карты памяти. Этот раздел
в формате FAT32 виден на любом компьютере, файл можно править обычным Блокнотом.
Изменения применяются при следующем включении платы.

Если ты подключён по SSH, раздел сначала нужно перемонтировать на запись:

```bash
mount -o remount,rw /boot
```

```bash
vi /boot/rpi-player.conf
```

```bash
reboot
```

Если файла на карте нет, используются значения по умолчанию из `/etc/rpi-player.conf.default`.

## Параметры

Синтаксис как в shell: `КЛЮЧ="значение"`, без пробелов вокруг `=`.

### Wi-Fi

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `AP_SSID` | `rpi-cam` | Имя сети |
| `AP_PASSPHRASE` | `camera1234` | Пароль WPA2, от 8 до 63 символов. Пусто = открытая сеть |
| `AP_COUNTRY` | `RU` | Код страны, от него зависят разрешённые каналы |
| `AP_HW_MODE` | `g` | `g` = 2,4 ГГц, `a` = 5 ГГц |
| `AP_CHANNEL` | `6` | Канал, должен подходить к диапазону и стране |
| `AP_HIDDEN` | `0` | `1` = скрыть имя сети |

### Адреса

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `AP_ADDR` | `192.168.50.1` | Адрес платы в её сети |
| `AP_PREFIX` | `24` | Длина префикса сети |
| `AP_DHCP_START` | `192.168.50.10` | Начало диапазона адресов для клиентов |
| `AP_DHCP_END` | `192.168.50.100` | Конец диапазона |
| `ETH0_DHCP` | `yes` | Получать адрес на Ethernet-порту по DHCP |

Если меняешь `AP_ADDR`, поменяй и диапазон DHCP, он должен быть в той же сети. Клиенты
Wi-Fi могут также обращаться к плате по имени `cam.lan`.

### Поток

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `HLS_PORT` | `8080` | Порт веб-сервера |
| `HLS_SEGMENT_SECONDS` | `2` | Длина сегмента в секундах |
| `HLS_LIST_SIZE` | `6` | Сколько сегментов держать в плейлисте |
| `MEDIA_FILE` | пусто | Какой файл играть, путь относительно `/data/media`. Пусто = самый свежий |

Закрепить файл можно ещё символической ссылкой `/data/media/current`.

Если закреплённый файл не читается, играет самый свежий из остальных.

### Пароли

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `ROOT_PASSWORD` | `player` | Пароль `root` для SSH и SFTP |
| `MEDIA_PASSWORD` | `media` | Пароль `media` для SFTP |

Пароли применяются при каждой загрузке. Пустое значение оставляет текущий пароль.

В `rpi-player.conf` пароли хранятся открытым текстом, поэтому их может прочитать любой, у
кого есть доступ к карте.

Вход по ключу: положи публичный ключ в `/data/ssh/authorized_keys_<имя_пользователя>`.

## Своя картинка «нет сигнала»

Залей файл `/data/media/placeholder.jpg`. Он будет показываться, когда играть нечего.

## Карта больше 512 МБ

Образ занимает 468 МБ и работает на карте большего размера, но раздел `data` остаётся
размером 200 МБ. Чтобы отдать под видео всю карту, после записи образа растяни последний
раздел. Видео и настройки при этом сохраняются. Операцию нужно делать на Linux.

С графическим интерфейсом:

1. Запусти `sudo gparted` и справа вверху выбери свою карту. Не перепутай её с диском компьютера.
2. Если разделы смонтированы, размонтируй их: правая кнопка → **Unmount**.
3. Правая кнопка по последнему разделу с меткой `data` → **Resize/Move**.
4. Растяни его до конца и нажми **Apply**.

Из командной строки (замени `sdX` на свою карту и проверь букву через `lsblk`):

```bash
sudo parted /dev/sdX resizepart 3 100%
```

```bash
sudo e2fsck -f /dev/sdX3 && sudo resize2fs /dev/sdX3
```

Проверить результат на плате:

```bash
ssh root@192.168.50.1 df -h /data
```
