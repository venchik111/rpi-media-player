# Быстрый старт

## Что понадобится

- Raspberry Pi 4 Model B и блок питания к ней
- Карта microSD или USB-флешка от 512 МБ. Загрузка с USB требует, чтобы загрузчик платы это поддерживал, на платах с завода до 2020 года его может понадобиться обновить
- Файл образа `sdcard.img` (как его получить, см. [Сборка](building.md))
- Устройство с Wi-Fi и программа для просмотра, например VLC

## 1. Запиши образ

1. Открой Raspberry Pi Imager.
2. «Выбрать ОС» → «Use custom» → выбери `sdcard.img`.
3. Выбери карту и нажми «Записать». Дополнительные настройки ОС, которые предлагает
   Imager, не применяй: образ сделан не на Raspberry Pi OS.

На Linux можно записать так (замени `sdX` на свою карту и проверь букву через `lsblk`):

```bash
sudo dd if=sdcard.img of=/dev/sdX bs=4M conv=fsync status=progress
```

## 2. Включи плату

Вставь карту и подай питание. Примерно через 30–40 секунд появится Wi-Fi сеть `rpi-cam`.
Подключись к ней с паролем `camera1234`.

Android может предупредить, что в сети нет интернета. Выбери «Оставаться в сети», иначе
телефон уйдёт на мобильный интернет.

## 3. Открой поток

В VLC: «Медиа» → «Открыть URL»:

```
http://192.168.50.1:8080/stream.m3u8
```

Пока видео не залито, идут цветные полосы «нет сигнала». Страница со встроенным плеером
есть по адресу `http://192.168.50.1:8080/`, но она работает не во всех браузерах
(нужна встроенная поддержка HLS). Надёжнее смотреть в VLC.

## 4. Залей видео

В WinSCP или FileZilla:

| Поле | Значение |
|---|---|
| Протокол | SFTP |
| Хост | `192.168.50.1` |
| Порт | `22` |
| Логин и пароль | `media` / `media` |
| Папка | `/data/media` |

Из командной строки:

```bash
sftp media@192.168.50.1
```

Внутри сессии выполни `put movie.mp4`, файл попадёт в `/data/media`.

Новый файл идёт в эфир сразу после окончания заливки, перезагружать ничего не нужно.

## Что важно знать

- **Какой файл играет:** самый свежий файл в `/data/media`, который читается как целое видео.
- **Форматы:** MP4 с H.264 и AAC идёт сразу. Другие форматы один раз перекодируются, пока
  это происходит, играет предыдущее видео. Поддерживаются расширения `mp4`, `m4v`, `mov`,
  `mkv`, `avi`, `ts`, `mts`, `m2ts`, `webm`, `flv`, `mpg`, `mpeg`, `h264`, `264`.
- **Место:** на разделе `data` свободно около 168 МБ. Старые файлы сами не удаляются, лишние
  удаляй по SFTP командой `rm`. Как получить больше места, см.
  [Настройка](configuration.md#карта-больше-512-мб).
- **Заливка под тем же именем** сразу перезаписывает старый файл, и при обрыве его не
  вернуть. Надёжнее заливать под новым именем.
- **После включения** поток запускается сам и крутит видео по кругу.

Перед реальным использованием [смени пароли](configuration.md#пароли).
