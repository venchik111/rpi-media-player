# Решение проблем

## Частые симптомы

| Симптом | Что проверить |
|---|---|
| Не видно Wi-Fi сети | Подожди 40 секунд после включения. Проверь `AP_COUNTRY` и `AP_CHANNEL`. Пароль должен быть от 8 символов, иначе сеть не поднимется |
| Сеть есть, поток не открывается | Проверь адрес `http://192.168.50.1:8080/stream.m3u8`. Android может уйти на мобильный интернет, ответь «Оставаться в сети» |
| Идут полосы «нет сигнала» | Читаемых видео нет, либо единственное ещё перекодируется |
| Залил новый файл, а играет старый | Файл не читается или загружен не полностью, он будет в `skipped=` в `player-ctl status`. Удали его и залей заново |
| Заливка обрывается с ошибкой | Закончилось место. Удали лишние файлы по SFTP или [расширь раздел](configuration.md#карта-больше-512-мб) |
| Нет звука | Проверь, есть ли звук в исходном файле, и не выключен ли он в плеере |
| Плата не загружается | Посмотри на вывод по HDMI и светодиоды. Запиши образ заново |

## Как попасть на плату

Через Wi-Fi:

```bash
ssh root@192.168.50.1
```

Если Wi-Fi не работает, подключи плату кабелем к роутеру. Она получит адрес по DHCP, его можно
посмотреть в настройках роутера. Также доступна консоль на HDMI и на последовательном порту
(`ttyAMA0`, контакты GPIO 14/15, скорость 115200).

## Что сейчас играет

```bash
player-ctl status
```

| Поле | Значение |
|---|---|
| `mode=video` | В эфире видео |
| `mode=placeholder` | В эфире «нет сигнала», причина в `reason=` |
| `source=` | Исходный файл |
| `cached=` | Перекодированная копия, которая реально играет |
| `pending=` | Файл, который сейчас перекодируется |
| `skipped=` | Последний пропущенный файл |
| `reason=no-media` | Видео нет |
| `reason=converting` | Единственное видео перекодируется |
| `reason=unreadable` | Подходящих файлов нет, есть только нечитаемые |

## Диагностика

Сводка для отчёта о проблеме:

```bash
ip -br addr; iw dev; lsmod | grep -E 'brcm|cfg80211'; dmesg | grep -iE 'brcm|firmware' | tail -20; tail -30 /var/log/messages; player-ctl status
```

Подробный запуск точки доступа, чтобы увидеть ошибку `hostapd`:

```bash
/etc/init.d/S42wifi-ap stop; hostapd -d /run/hostapd.conf
```

Перезапустить поток и заново выбрать файл:

```bash
/etc/init.d/S70player restart
```

```bash
player-ctl reload
```

Журнал `/var/log/messages` хранится в оперативной памяти и очищается при перезагрузке.
Сообщения плеера в нём отмечены меткой `rpi-player`.
